# 03 — 形態學為主的完整分析（6 條件 × 2 技術重複）

**日期**：2026-08-15
**狀態**：有效
**程式**：`ifquant/run_study.py`、`ifquant/morphology.py`、`ifquant/groups.py`
**輸出**：`results/study_per_cell.csv`、`study_per_field.csv`、`study_reproducibility.csv`、`study_snr.csv`、`study_qc.png`

---

## 一句話結論

> **沒有任何指標能區分這六個條件。** 不是因為差異不存在，而是因為
> **視野與視野之間的變異（technical SD）跟條件之間的差異（condition SD）一樣大**。
> 最便宜的解法：**每個孔多拍幾個視野，從現在的 2 個增加到約 13 個。**
> 這不需要重做任何生物實驗。

## 實驗設計（使用者確認）

| 條件 | rep1 (blue/green/red) | rep2 (blue/green/red) |
|---|---|---|
| control1 健康 | 765 / 766 / 767 | 807 / 808 / 809 |
| control2 疾病 | 768 / 769 / 770 | 810 / 811 / 812 |
| treatment1 | 795 / 796 / 797 | 813 / 814 / 815 |
| treatment2 | 798 / 799 / 800 | 816 / 817 / 818 |
| treatment3 | 801 / 802 / 803 | 819 / 820 / 821 |
| treatment4 | 804 / 805 / 806 | 822 / 823 / 824 |

**關鍵設計事實**：

- treatment1–4 是**四種不同的處理**（劑量／藥物），不是四個重複
- 每個條件只有**一個孔** → 生物學 n = 1
- rep1 / rep2 拍攝時間 17:11–17:32，**同一個 session、同一張片** → 這是
  **technical replicate（技術重複），不是 biological replicate**
- 因此**不做任何統計檢定**。在技術重複上跑檢定是 pseudoreplication。

## 發現 1：紅色（iNOS）是唯一乾淨的通道

各通道跨 12 個 field 的曝光時間：

```
BLUE   0.125 / 0.1667 / 0.2 s      全距 60%   → 有混淆
GREEN  0.625 / 0.7692 s            全距 23%   → 有混淆
RED    1.0000 s（全部）             全距  0%   → 乾淨
```

紅色訊號夠暗，**自動曝光撞到 1 秒的上限**，無法再 normalize，
所以 12 張紅色影像是在完全相同的條件下拍的。

**這是整批資料裡唯一絕對強度可以跨 field 比較的通道。**

---

## 發現 2：MyD88 絕對強度失效的直接實證

你的分組意外提供了一個天然對照 —— health 與 disease 在兩次重複之間**對調了曝光**：

| 條件 | rep1 | rep2 |
|---|---|---|
| control1 健康 | 0.6210（曝光 0.7692s） | 0.7247（曝光 0.6250s） |
| control2 疾病 | 0.8709（曝光 0.6250s） | 0.6089（曝光 0.7692s） |

```
rep1:  健康 0.6210  <  疾病 0.8709     ✓ 符合「疾病 MyD88 上升」的預期
rep2:  健康 0.7247  >  疾病 0.6089     ✗ 完全相反
```

**結論方向隨曝光翻轉。** 這不是理論推測，是同一批樣本上量到的。
`green_cyto_mean` 這個指標不可用於任何組間比較。

## 發現 3：訊噪比 —— 真正的瓶頸

Spearman 在 n=6 條件下太不可靠（要 ρ > 0.83 才顯著），所以改為直接量測：

- **technical SD** = 視野間散布，由 rep1−rep2 的差算出
- **condition SD** = 六個條件平均值的散布
- **SNR** = condition SD / technical SD，要 > 1 才可能分辨

| 指標 | 類別 | tech SD | cond SD | SNR | 需要視野數 |
|---|---|---|---|---|---|
| cell_nuc_area_ratio | shape* | 6.6% | 9.3% | **1.41** | 5 |
| cell_area | shape* | 11.6% | 13.6% | 1.17 | 7 |
| nuc_area | shape | 7.0% | 7.9% | 1.12 | 8 |
| nuc_aspect | shape | 1.4% | 1.5% | 1.06 | 8 |
| n_nuclei（細胞密度） | count | 18.1% | 16.7% | 0.92 | 11 |
| red_cyto_mean（iNOS） | intensity | 8.4% | 7.7% | 0.91 | 11 |
| green_nc_ratio | intensity | 5.7% | 4.9% | 0.86 | 13 |
| nuc_circularity | shape | 1.3% | 1.1% | 0.80 | 15 |
| green_cyto_mean | **CONFOUNDED** | 12.5% | 9.5% | 0.76 | 16 |
| green_cell_cv | intensity | 13.5% | 10.0% | 0.74 | 17 |
| nuc_solidity | shape | 0.5% | 0.3% | 0.70 | 19 |
| red_cell_cv | intensity | 17.7% | 11.9% | 0.67 | 20 |
| red_nc_ratio | intensity | 5.0% | 2.0% | 0.40 | 56 |

**沒有任何指標的 SNR 達到 1.5。** 中位數需要 **13 個視野/孔**，目前只有 2 個。

### 一個重要的區分

形態學指標的 **technical SD 很小**（nuc_circularity 1.3%、nuc_solidity 0.5%）——
**量測本身是精準的**。問題是這些條件之間的核形態差異也同樣小（1.1%、0.3%）。

也就是說：**不是量不準，而是核形態在這些條件之間可能真的沒什麼差別。**
這本身是一個有意義的（陰性）觀察。

相對地，細胞密度的 technical SD 高達 18.1% —— 細胞在孔裡分布不均，
兩個視野根本代表不了一個孔。

## 發現 4：DAPI 漏光到綠色通道

逐細胞檢驗（同一視野內，核內 DAPI 亮度 vs 核內綠色亮度）：

```
跨 field 的中位數相關 = +0.364
```

中度相關。MyD88 是細胞質蛋白，核內綠色訊號有一部分應該是 DAPI 漏光。
這會灌水 `green_nc_ratio`，該指標要保守解讀。

（先前 field 層級量到的 +0.79 高估了，那個數字混入了空間結構的共變。）

## 所以「哪個治療比較好」？

**答不了。** 三個獨立的理由，每一個都足以單獨否決：

1. 生物學 n = 1 —— 沒有統計方法可以比較單一樣本
2. 所有指標的 SNR < 1.5 —— 條件差異埋在視野噪音裡
3. MyD88 絕對強度已被證實隨曝光翻轉

任何基於這批資料的治療排名都不會是真的。

---

## 建議：依投報率排序

### 1. 每個孔多拍視野（最便宜，馬上可做）

**從 2 個增加到 13 個以上。** 如果玻片還在，這只是重新上機拍照，
不需要重做任何生物實驗，就能把 SNR 拉到可用範圍。

拍的時候請務必：**相機切 M 模式，固定曝光/ISO/白平衡**。
這會同時解決曝光混淆，讓綠色通道也變成可用。

### 2. 生物重複（要新實驗，但無可取代）

至少 3 次獨立實驗（不同批細胞、不同天）。沒有這個，
無論拍多少視野，統計上的 n 都還是 1，論文過不了審。

### 3. secondary-only 對照（一張就夠）

定出加性 offset。

### 4. 相機 tone curve 校正

優先度最低，見 [01](01-camera-characterisation.md)。使用者已表示暫不處理。

## 這批資料現在能拿來做什麼

雖然不能下生物學結論，但它是**有效的 pilot**：

- 已經量出每個指標的 technical SD → 可以直接算出正式實驗需要多少視野
- 已經證實紅色通道乾淨、綠色通道被混淆 → 下次拍攝的設定有依據
- pipeline 已經驗證可跑通 12 個 field → 資料補齊後可立即重跑

**把它當成 power analysis 用，而不是當成結果用。**
