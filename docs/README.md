## 目前的總結論（一句話）

> **假設曝光固定（`--no-exposure`）比除以曝光好** —— DAPI 內部對照的噪音從 11.2% 降到 3.7%。
> 這樣做之後唯一站得住的觀察是「**健康組 MyD88 低於疾病組，兩次重複方向一致（0.919×）**」。
> **四個治療都沒有可重複的下降**，但這個量測方法天生偏向測不到整體下降，
> 所以不能解讀為治療無效。「哪個治療比較好」仍然答不了。

詳見 [04-fixed-exposure-assumption.md](04-fixed-exposure-assumption.md)。

## 已確立的事實

- **紅色（iNOS）通道乾淨**：12 張全部 1.0000s 曝光，自動曝光撞到上限。
  這是唯一絕對強度可跨 field 比較的通道。
- **不要除以曝光時間**：DAPI 內部對照證明它讓噪音變三倍。改用 `--no-exposure`。
  代價是量測變成「相對於視野平均」，對整體升降部分盲、偏向保守。
- **形態學量測很精準但條件間差異也很小**：nuc_solidity 的 technical SD 只有 0.5%，
  條件間差異 0.3%。核形態在這些條件之間可能真的沒差別。
- **生物學 n = 1**：六個條件各一個孔，全部在同一個 20 分鐘的 session 拍完。
  rep1/rep2 是技術重複。

## 待補資料（依投報率排序）

1. **每孔多拍視野**：2 → 13 個以上。玻片還在的話不需要重做實驗。
   **拍攝時務必用 M 模式固定曝光**，可同時解決曝光混淆。
2. **生物重複**：至少 3 次獨立實驗。沒有這個，統計上的 n 永遠是 1。
3. **secondary-only（只打二抗）對照影像** — 定出加性 offset
4. **相機 tone curve 校正 bracket** — 使用者已表示暫緩
