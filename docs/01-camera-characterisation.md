# 01 — 從影像反推相機參數

**日期**：2026-08-15
**狀態**：有效
**資料**：`HMC3 activated marker IF GMy88 R INOX/`，36 張（12 個 field × 3 通道）
**程式**：一次性 probe script，核心結論已併入 `ifquant/core.py` 的註解

---

## 背景

相機是 Olympus E-M5 Mark II，`ExposureProgram = 2`（自動）、`WhiteBalance = 0`（自動）。
問題：在拿不到相機當時設定的情況下，能從影像本身反推多少？

---

## 方法：雙通道定比值法

DAPI 影像裡 R channel 精確為 0，但 B 和 G 都有值 —— DAPI 的發射光漏進了綠色 Bayer 像素。

關鍵推論：**同一個螢光分子 + 固定的濾片響應 → 真實線性訊號的 G:B 比值必定是常數。**

所以觀察到的顯示值比值如果隨亮度變化，那個變化就是 tone curve 造成的。

---

## 結果

### (1) Tone curve 確實有可測量的曲率

`PB154765`（DAPI），依 B 值分十等分：

| B 值 | 平均 G | G/B |
|---|---|---|
| 130.8 | 84.0 | 0.6020 |
| 161.9 | 103.0 | 0.6362 |
| 199.0 | 131.7 | 0.6607 |
| 236.2 | 164.0 | 0.7158 |

從 0.602 爬到 0.716（**+19%**）。若響應是線性的，這個比值必須是常數。
不是常數 → 有真實的高光壓縮（shoulder）。

### (2) 自動白平衡沒有明顯漂移 —— 好消息

12 張 DAPI 影像的 G/B 比值：

```
0.6465 – 0.6605，全距 2.2%
```

**AWB 不是混淆因子，這個風險可以劃掉。**

### (3) 自動曝光把亮度normalize掉了 —— 壞消息

```
exp = 0.625s  n=5   8-bit 平均 = 168.96
exp = 0.769s  n=7   8-bit 平均 = 166.66
correlation(曝光, 8-bit 平均) = -0.225
```

曝光差 23%，8-bit 平均卻只差 1.4%，且相關性為負。
**相機在主動把場景亮度拉平。**

---

## 結論

### 可以反推的

- **Tone curve 的曲率部分**（偏離冪次律的 shoulder / toe）
- **AWB 穩定性** — 已驗證穩定（2.2%），不需處理
- **Black level** — R/B channel 出現精確的 0，代表相機已扣掉底電位
- **Flat-field** — 已在 L2 用 12 張影像的中位數估出

### 反推不出來的：gamma 指數 γ 本身

兩條路都塞住：

1. **雙通道定比值法對 γ 是盲的。**
   若 f(x) = x^γ，則 G^γ = k·B^γ → G = k^(1/γ)·B。
   顯示值的比值與 γ 無關 —— 冪次律是尺度不變的。
   這招只看得到「偏離冪次律」的部分。

2. **曝光變化法被自動曝光汙染。**
   理論上同場景 + 兩個已知曝光就能解 γ，但 AE 讓曝光與場景亮度反向綁死，無法分離。

### γ 不確定性的影響

T/C 比值大約隨 γ 呈冪次關係。γ 在 2.0 – 2.8 之間 → T/C 變動約 ±10%。

**這比 offset 的不確定性（見 [02](02-all-fields-confound.md)）小得多，優先度較低。**

---

## 建議的補救

**一次校正拍攝，約 10 分鐘，不需要重做實驗。**

M 模式，對任何靜止的螢光物體，拍一組已知曝光的 bracket（例如 1/8、1/4、1/2、1s）。
同場景 + 已知曝光比 → γ 直接解出。

γ 是**相機 + picture mode 的性質，不是樣本的性質**，所以量一次可以回頭套用到所有舊資料。
