## 一句話結論

> **這批資料無法區分「treatment 效應」與「細胞密度經由自動曝光造成的假象」。**
> 觀察到的 field 間 1.22 倍差異，在數值上與曝光時間比值（1.23）**完全相同**，
> 扣掉曝光後的殘餘訊號是 **0.993**（1.00 代表毫無額外訊號）。

## 發現 1：兩個曝光等級把 field 完美分開

```
0.625s (n=5):  0.7424  0.7777  0.8600  0.8792  0.8890
0.769s (n=7):  0.6348  0.6369  0.6452  0.6969  0.7007  0.7064  0.7308

min(0.625s) = 0.7424  >  max(0.769s) = 0.7308   → 零重疊
```

乍看之下這是很漂亮的分組訊號。**但下一節說明為什麼不能採信。**

---

## 發現 2：那個分離「就是」1/曝光，沒有額外訊號

```
實測 cyto_mean 比值        = 1.2222
純曝光時間比值             = 1.2308
扣掉曝光後的殘餘           = 0.9930   ← 1.00 代表毫無額外訊號

8-bit 原始平均，0.625s 組  = 168.96
8-bit 原始平均，0.769s 組  = 166.66
→ 自動曝光把 8-bit 亮度拉平到 1.4% 以內
```

原因：`cyto_mean = 線性化後的 8-bit / 曝光時間`。
自動曝光已經把 8-bit 亮度normalize掉了，所以這個數值幾乎完全由 `1/曝光` 決定。

**這不代表計算錯了** —— 除以曝光時間是必要且正確的。
問題在於：曝光是相機依據「整個視野的總亮度」決定的，而總亮度受很多東西影響。

---

## 發現 3：細胞密度足以完全解釋曝光差異

```
核數/field，0.625s 組 = 127.6
核數/field，0.769s 組 =  99.3
密度比值              = 1.2852
曝光隱含的亮度比值    = 1.2308      ← 密度比值已經蓋過它
```

**因果鏈**：細胞越密 → 視野總亮度越高 → 自動曝光縮短 → 除以較小的曝光 → 每細胞數值被灌水。

密度直接經由 AE 迴路污染 per-cell 數值，即使每顆細胞的真實 MyD88 完全一樣。

驗證：

```
corr(核數, cyto_mean)，全部 12 個 field        = +0.591
corr 在 0.625s 組內（曝光固定）                = +0.043  (n=5)
corr 在 0.769s 組內（曝光固定）                = +0.206  (n=7)
```

**固定曝光後相關性崩塌到接近 0** —— 證實那個 +0.591 完全是曝光分組造成的，
不是「密度高的地方細胞真的比較亮」這種生物學關係。

## 發現 4：時間戳推翻了先前的分組假設

```
17:11:22  PB154766   exp=0.7692s   n=125
17:11:43  PB154769   exp=0.6250s   n=129
17:23:33  PB154796   exp=0.7692s   n= 63   ← 11.8 分鐘空檔
17:25:00  PB154799   ...
（其後每 20 秒到 2 分鐘一張，連續到 17:31:54）
```

先前的分析（沿用自更早的對話）假設 **766 = control、769 = treatment**。

但這兩張只相隔 **21 秒**。21 秒內不可能換玻片、換 coverslip。
**這個分組假設不成立**，除非兩個條件本來就在同一張玻片的不同區域（需要使用者確認）。

整批唯一的大空檔是 **11.8 分鐘（769 → 796）**，那才像是換片的動作。
但這樣切出來是 2 個 field vs 10 個 field，不像常規的分組設計。

## 發現 5：飽和嚴重且分布不均

```
含飽和像素的細胞比例：8.8% – 70.0%
超過 40% 的 field：805、820、823
```

`PB154820` 有 **70%** 的細胞含飽和像素，QC 後只剩 23 顆細胞。
這些 field 的最亮細胞被過濾掉，平均值被**向下**拉，幅度未知。

## 對先前結論的影響

**先前 README 報告的 `T/C = 1.66`（區間 1.33 – 2.15）現在不安全，理由有二：**

1. **分組假設本身有問題**（發現 4）。766 vs 769 不是已確認的 control vs treatment。
2. **即使分組正確，效應也被曝光/密度混淆**（發現 2、3）。
   766 vs 769 這一對在 offset = 0 時的比值是 1.333，而這兩張的曝光比是 1.231，
   殘餘只有 **1.083** —— 也就是扣掉曝光後只剩 8%，不是 33%，更不是 66%。

**README 已同步更新。**

---

## 這不代表「沒有效應」

要說清楚：以上是說**這批資料無法判斷**，不是說效應不存在。
真實效應可能存在，只是被自動曝光和密度混淆到無法分離。

---

## 需要什麼才能得到結論

依重要性排序：

1. **control / treatment 的分組**（使用者提供）
   沒有這個，後面全部免談。

2. **secondary-only 對照影像**
   定出加性 offset。目前 offset 是自由參數，效應量只能給區間。

3. **能打破 AE 混淆的資料**。三選一：
   - 重拍時用 **M 模式固定曝光** ← 最乾淨
   - 提供每個 field 的**細胞密度是否本來就該有差異**的先驗知識
   - 若 treatment 本身會改變細胞數（例如影響增殖或存活），那密度與強度天生共變，
     **必須用固定曝光重拍才能分離**，沒有事後補救的方法

4. 相機 tone curve 校正（見 [01](01-camera-characterisation.md)），優先度最低。

## 附帶的方法學備註

- 跨 field 比較時 offset 設為 0。共同的 offset 不影響 field 排序，
  而套用一個猜測的常數反而會扭曲 field 之間的比值。
- `PB154796` 只有 63 個核，是其他 field 的一半，且緊接在 11.8 分鐘空檔之後。
  可能是換片後的第一張、對焦或位置還沒穩定。分析時值得單獨標記。
